Falta configurar la conexión

Este panel necesita conectarse a Supabase para ver los jugadores y controlar el juego en tiempo real desde cualquier dispositivo.

Completá el archivo supabase-config.js siguiendo README-SUPABASE.md y volvé a abrir esta página.

🚫

No se pudo conectar con la base de datos

La configuración está cargada, pero Supabase devolvió un error al consultar los datos. Esto suele pasar por alguna de estas causas:

• El proyecto de Supabase está pausado por inactividad (entrá al panel y reactivalo).
• No se corrió el SQL completo de README-SUPABASE.md (faltan tablas o políticas RLS).
• La URL o la clave en supabase-config.js están mal copiadas.
